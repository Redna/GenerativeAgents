# Memory Storage & Retrieval System (LLM Guidelines)

## Core Philosophy
The Generative Agents memory system is built around a single unifying principle: **Vectors AND graph edges live in the same Qdrant store.**
There are no external JSON files mapping relationships, and no numpy arrays floating around. All memory interactions flow through a tightly controlled schema.

## Database Backend
- **Repository**: `QdrantMemoryRepository` (`agents/memory/repository.py`)
- **Backend Type**: Qdrant Vector Database
- **Embeddings**: `FastBGEEmbedding` model converts text to 384-dimensional vectors.

## Memory Types (EventType)
Every memory explicitly belongs to one of these types:
1. `EVENT` - A direct physical action the agent took.
2. `OBSERVATION` - Something the agent saw someone else do, or an overheard snippet of conversation.
3. `CHAT` - A direct semantic conversation the agent participated in.
4. `THOUGHT` - An internally generated reflection, insight, or plan.

## The Qdrant Payload Schema
When an event is stored, it is embedded and saved with the following rigid payload structure:
```json
{
  "str_id": "uuid-string-here",
  "content": "The actual memory text (e.g., 'overheard Klaus say to Maria: I love coffee')",
  "memory_type": "observation",
  "depth": 1,
  "created_ts": 1708892345.0,
  "importance": 0.85,
  "entity_id": "Giorgio Rossi",
  "related_events": [{"id": "uuid-of-other-event", "relation": "derived_from"}]
}
```

## Insertion Rules
1. All semantic memories must be converted to `PerceivedEvent` objects before insertion.
2. `poignancy` (importance) determines how quickly a memory decays and whether it triggers System 2 reflection.
3. Overheard snippets (`"overheard X say to Y: ..."`) receive an automatic high-signal heuristic boost to ensure they are retained.

## Retrieval Process (The 3-Stage Pipeline)
When the `AgentBrain` needs to remember something, it uses the `AssociativeMemoryLayer`, which executes a 3-stage pipeline:
1. **Semantic Search (ANN)**: Uses `QdrantMemoryRepository.retrieve()` to fetch the top 20 memories semantically similar to the current context query.
2. **Graph Expansion**: Uses `QdrantMemoryRepository.get_context()` to execute a Breadth-First Search (BFS) over the `related_events` payload field, discovering associated memories (like thoughts derived from a core observation) that might not match the query textually.
3. **Contextual Reranking**: Passes the combined expanded pool to a DSPy `ContextualReranker`, which executes a single LLM call to score and return the top 10 most contextually vital memories for the current situation.
